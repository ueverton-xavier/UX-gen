# UXIA

App de conversa para gerar **imagens e vídeos** com modelos abertos hospedados em
Hugging Face Spaces: FLUX.1 [dev], [schnell] e Kontext, CogVideoX, AnimateDiff Lightning e LTX-Video.

- Instale no Android: abra o link do GitHub Pages no Chrome → ⋮ → **Instalar app**.
- Nada é salvo no aparelho: conversa e imagens ficam só na memória; só grava o que você tocar em **Salvar**.
- Token do Hugging Face (opcional) fica só na memória, nunca no código.
